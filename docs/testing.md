# QA Checklist

## Functional checks
- Verify all pages render correctly in desktop and mobile.
- Confirm sections and blocks appear in the expected order.
- Check that theme settings and schema values display properly.

## Localization checks
- Test content in English and Arabic.
- Verify RTL layout direction and text alignment.
- Ensure localized strings render without broken formatting.

## Performance checks
- Confirm pages load quickly and maintain smooth interactions.
- Review image size and media loading behavior.
- Check that custom JavaScript does not introduce unnecessary delays.

## Accessibility checks
- Verify keyboard navigation and focus states.
- Check contrast and readable text sizing.
- Ensure buttons, links, and forms are clearly labeled.

## Ecommerce checks
- Review product page purchase flow.
- Confirm cart, variant selection, and add-to-cart behavior work correctly.
- Check collection and search experiences for clarity and conversion flow.

## Final release checks
- Confirm no unnecessary file modifications were introduced.
- Verify the theme remains maintainable and aligned with the project rules.
- Review the implementation against the AVICARE PRO brand expectations.
