# Reusable Components

## Existing reusable foundation
The theme already contains a strong component base that can be reused for AVICARE PRO development.

### Core UI components
- Button patterns
- Icon rendering
- Image and media handling
- Product cards
- Collection cards
- Form controls such as quantity selectors and swatches
- Localization components
- Search and predictive search modules

### Layout components
- Header sections and header action snippets
- Footer section patterns
- Section wrapper patterns
- Grid and spacing helpers

## Component guidance
When building new features:
- Reuse existing snippets before creating new ones.
- Maintain consistency with the present component architecture.
- Keep new components focused and configurable through settings where possible.

## Expected AVICARE PRO additions
Likely future components include:
- premium hero modules
- trust and science storytelling blocks
- product comparison or benefits modules
- conversion-focused CTA components
- RTL-friendly navigation and localization components
